# 03 Grid-Level berechnen

## Ziel

Aus `Grid unten`, `Grid oben` und `Anzahl Grids` werden feste Preislevel berechnet.

## Eingaben

- Grid unten
- Grid oben
- Anzahl Grids

## Pruefung

- Grid unten ist groesser oder gleich `0`.
- Grid oben ist groesser als Grid unten.
- Anzahl Grids ist groesser als `1`.

## Aktion

- Grid-Abstand berechnen.
- Preislevel von unten nach oben berechnen.

## Ausgabe

- Liste der Grid-Level
- Grid-Abstand

## Testziel

Bei gleichen Eingaben muss immer exakt dieselbe Level-Liste entstehen.
